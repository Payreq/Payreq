    Security

    No credentials, ever

    PAYREQ does not request bank passwords, OTPs, or PINs — at any point, for any reason.

    Generated locally

    Requests are built and encoded entirely in your browser. Nothing is sent to a server.

    Local history only

    Recent requests are stored in this browser's local storage and never transmitted elsewhere.

    No fabricated confirmations

    PAYREQ never claims a payment is completed without genuine, verified provider confirmation.
